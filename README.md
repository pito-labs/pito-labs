## Selected Projects

### [Codexion](https://github.com/pito-42/codexion)

### [A-Maze-ing](https://github.com/pito-42/a-maze-ing)

Python製の設定駆動型迷路生成・可視化アプリケーションです。2人チームで、私は迷路生成ロジックと描画を担当しました。DFS / Primによる生成と、BFSによる最短経路探索を実装しています。

### [Push Swap](https://github.com/pito-42/push_swap)

制約されたスタック操作だけで整数列を整列するCプログラムです。入力サイズに応じてアルゴリズムを分け、大規模入力ではLISと操作コスト計算を利用しています。
